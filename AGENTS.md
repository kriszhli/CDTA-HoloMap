# Project instructions

- Run this project locally. Do not publish or deploy to ChatGPT Sites or another host unless the user explicitly requests it.
- The Git repository root is this folder; the application is in `cdta-live/`.
- The GitHub remote is `https://github.com/kriszhli/CDTA-HoloMap.git`.
- After every completed change, run the relevant checks and make a Git commit with a descriptive message. Do not leave completed work uncommitted.
- Never commit credentials, `.env` files, dependency folders, or generated build output.
- Preserve actual CDTA live data, GPS-corrected prediction, stationary stop circles, and the 3D holographic map.
